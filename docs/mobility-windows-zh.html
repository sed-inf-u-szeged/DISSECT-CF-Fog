Mobility 训练窗口 v1

本步骤把已完成的模拟采样变成监督学习输入与目标。没有训练模型，没有拟合标准化参数，没有改动 Java 模拟或 UI。

已经核验的来源

Windows 批次：20261107T190027Z-5c3b0fc38571。12 条路线、每条 3 种速度（2.0、4.1、6.0 m/s）、种子 42，36 次运行、每次 121 条记录，共 4,356 条固定窗口内采样。每次 1 台设备、2 个节点。该批次在上传文件复核中通过配置、文件哈希、采样、派生运动量及最终记账检查。

窗口定义

在每个 run/device 内，以 60 秒步长移动窗口：8 个连续历史观测点（跨度 7 分钟）→ 60 秒后的真实位置。路线分组在构建之前固定，窗口不跨运行边界。

每次运行第一条速度无效。包含它的第一个候选窗口跳过；其余窗口保留，包含断连时的轨迹。121 条记录能形成 113 个候选窗口，跳过 1 个，剩 112 个。第一窗口使用原始索引 1–8，目标索引 9（索引从 0 开始）；最后窗口用索引 112–119，目标 120。

速度、方向角由前一条到当前条的位置派生。因此首个历史点的运动特征还用到了它之前的一个观测点，这是过去信息，不是未来信息。8 个显式位置点覆盖 7 分钟；这些派生运动特征的最早来源可再向前追溯 1 分钟。

模型输入与目标

字段定义
x[8][6]每个历史点：相对预测发出时位置的东向距离、北向距离、观测速度、sin(方向角)、cos(方向角)、方向角有效标记。
y[2]60 秒后相对预测发出时位置的东向位移、北向位移，单位米。
坐标转换固定参考纬度 47.73°、经度 18.27°，地球半径 6,378,137 米的局部等距圆柱近似：E=R·cos(lat0)·(lon−lon0)，N=R·(lat−lat0)，角度转弧度。不是精确地表距离；可逆转换回经纬度后按球面距离评估。
方向角缺失静止点方向角无效时用 sin=0、cos=0、有效标记=0。初始速度无效时跳过包含该行的窗口，不以零速度替代。
元数据case、run、split、原始索引、时间、当前锚点经纬度、origin_node、目标经纬度用于追溯和评估。模型只接收 x，监督目标为 y；不可把元数据整行自动作为特征。

速度是相邻观测点的端点位移÷60秒，不是瞬时速度；在拐角处可以小于配置速度。输入不使用路线航点、路线 ID、目标真实位置或未来连接状态。最终排空产生的额外观测不进入学习窗口。

输出与重现

脚本只需 Python 标准库及已安装的两个检查器。读取明确指定的完整批次，在 sim_res/mobility-windows 下创建唯一目录，包含 train.jsonl、validation.jsonl、test.jsonl 和 windows.json。每行一个窗口；JSONL 易于核查，后续训练程序可装成张量。windows.json 记录字段顺序、投影、来源及输出哈希、逐场景计数、状态。只有 COMPLETE 可用。重跑新建目录，不覆盖或累计合并重复窗口。

构建前核对 36 个场景、分组、原始结果哈希和采样；写入后读回检查时间对应及坐标还原；发布 COMPLETE 前复核源数据。原始批次保持不变。安装器只新增 3 个文件；已有同名且内容不同则停止。安装记录存到项目外的备份目录。
